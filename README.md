# Downtab

A macOS app switcher that works like ⌘Tab, and lets you drop down to a single window of an app.

**This repo is archived.** Downtab now lives at [doubleloop-io/downtab](https://github.com/doubleloop-io/downtab).

Download and install instructions: https://doubleloop-io.github.io/downtab/

Releases: https://github.com/doubleloop-io/downtab/releases
